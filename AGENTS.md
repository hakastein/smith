# smith — правила для агентов

- Публичный репозиторий: никаких внутренних хостов, имён людей, токенов, путей машин и названий компаний. В примерах —
  `example.com`. Номера задач трекера в коммитах, коде и документации не пишутся.
- smith запускает один этап агента. Оркестрации, workflow, конфигов этапов и скриптовых движков в нём нет: порядок
  этапов пишет сервис-потребитель на Go. Предметной логики потребителей (ревью, тикеты) тоже нет.
- Знание конкретного драйвера (claude, codex) живёт только в его пакете: общий слой не знает их имён и механизмов.
- Публичный API — только то, что нужно потребителям; остальное — в `internal/`.
- Документация, комментарии и сообщения коммитов — на русском и описывают только текущее состояние: без «раньше»,
  «теперь», «переименовано».
- Тесты проверяют поведение через публичный API пакета: состояние, данные, коды выхода. Формулировки текстов
  (ошибок, логов, заданий) тестами не проверяются. Интеграционных наборов на самописных подделках CLI агента нет:
  работоспособность драйверов проверяется живыми прогонами.
- Внешние команды запускаются через `agent.Group`: своя группа процессов, отмена убивает группу.
- `make go` — gofmt, vet и тесты — зелёный перед каждым коммитом.
